# Documentation Archive

This directory keeps superseded **public-facing documentation** without cluttering the active `docs/` tree.

## Rules

- Active documentation lives in the repository root and `docs/`.
- Materially superseded public docs may be snapshotted here under an ISO-date directory before replacement.
- `docs/Plans_/` and its TODO/build records are **not** moved here; they remain in their original location as requested and as project provenance.
- Archived documents are historical evidence, not current implementation or assurance claims.
- Git history remains the authoritative line-level change history; this archive exists for convenient document-level reference.
